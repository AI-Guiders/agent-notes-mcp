# Соглашение: шапка ADR (agent-notes-mcp)

Зеркало [cascade-ide ADR convention](../../../cascade-ide/docs/adr/snippets/adr-related-links-convention.md) для репозитория MCP.

| Поле | Правило |
|------|---------|
| **Статус** | `Accepted` / `Proposed` / `Superseded` — без длинных скобок в одной строке |
| **Дата** | Дата принятия |
| **Обновлено** | Одна строка + ссылка на § История, если есть |
| **Канон KB** | Для зеркальных ADR — строка **Канонический текст (KB):** с путём в `knowledge/adr/` |

Связи — `## Связанные ADR` (таблица), не `**Связано:**` в абзаце.

Перед `## Контекст` — `---` после таблиц шапки.
